# AGENTS.md

## Documentation

For all technical documentation:

- Follow Mintlify components and structure conventions.
- Start each page with YAML frontmatter containing `title` and `description`.
- Use clear, direct, user-focused technical writing.
- Prefer Mintlify-native components for procedures, API docs, callouts, and media.
- Keep examples complete, realistic, and safe.

For full documentation standards, see:

- `docs/style/mintlify-writing.md`

## Durable documentation

Document usage, concepts, architecture, and verification in normal Mintlify pages. Do not commit implementation plans, agent transcripts, task ledgers, or generated planning directories. Track work in GitHub issues and PRs; keep temporary execution notes outside version control.
