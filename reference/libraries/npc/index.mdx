Use the NPC library to put animated models in a Minestom world. An NPC can greet nearby
players, turn its head, move, or show a different animation to one player.
You can use it from Java or Kotlin in your own server. Grounds services are not required.

## Start with one visible NPC

The [first NPC guide](/reference/libraries/npc/getting-started) gives you a small finished
model and its resourcepack. Add the library to your project, load the files, and place the
NPC in an existing instance. You do not need Blockbench or the model compiler to start.

## How the pieces fit together

The **server content** describes the NPC's parts, positions and animations. Your server
loads it and creates the display entities.

The **resourcepack** supplies the graphics that Minecraft uses to draw those entities.
Players need the matching pack to see the model correctly. Loading a model on the server
does not send its pack to players.

The **model** is the reusable definition. An **NPC handle** controls one instance of that
model in the world. You can create several NPCs from the same loaded model.
