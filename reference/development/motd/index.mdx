---
title: "Minecraft MOTD library"
description: "Use a standalone Vanilla Java server-list viewer, inline editor, and text-processing library."
---

`@groundsgg/motd` lets you display and edit a Minecraft Java server entry. You
can use the pure TypeScript core in Node.js, the DOM adapter in any browser
framework, or the optional React adapter. You do not need the Grounds Portal,
an account, React, or a connection to a Minecraft server to use the core.

The viewer targets the selected Vanilla client profile. It displays supplied
status snapshots, static colors and decorations, native obfuscated text, and
optional client-menu panorama motion. It does not simulate continuously changing
MOTD frames, scrolling, blinking, or animated gradient phases.

<Note>
  Native fidelity is the target, not a blanket verification claim. Client
  profiles retain explicit reference coverage and approximation diagnostics.
  Original Minecraft textures and client binaries are not included in the npm
  package.
</Note>

## Choose your entry point

| Entry point                  | Use it for                                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| `@groundsgg/motd`            | Parsing, documents, layout, status evaluation, serialization, and diagnostics without a DOM. |
| `@groundsgg/motd/dom`        | A display-only viewer, inline editor, client comparison, and local image import.             |
| `@groundsgg/motd/react`      | React components wrapping the same DOM implementation. React is an optional peer.            |
| `@groundsgg/motd/styles.css` | The local renderer/editor stylesheet and bundled font references.                            |
